# 8번 승강장 (Platform 8) - 세이브 완전 초기화 & 즉시 8번 승강장 치트 모드
**Platform8 MasterMod (v1.0 - UMG Anomaly HUD & Instant Platform 8)**

《8번 출구》용 `Exit8_MasterMod` 를 《8번 승강장》 구조에 맞게 다시 만든 모드입니다.
두 게임은 같은 엔진 코드베이스(실행 파일 이름도 `Exit8-Win64-Shipping.exe`)지만, 8번 승강장은 복도 대신 열차 칸을 지나가며 클래스/변수 이름과 규칙이 다릅니다.

---

## 1. 8번 출구와 다른 점 (게임 규칙)

* **뒤로 갈 수 없습니다.** 지나온 연결문은 잠깁니다. 8번 출구처럼 "이변이면 U턴" 이 아닙니다.
* 이변마다 **정해진 대처법**이 있습니다 (숨은 광고는 찾아서 계속 바라보기, `8→ 9← 4→` 는 순서대로 문 터치, 침수는 달리기, 무해한 이변은 그냥 진행 등).
* 대처를 틀리면 게임오버 → 처음 역(零山, L0)으로 돌아갑니다.
* 칸을 제대로 넘어갈 때마다 역이 하나 진행되고, **L0 → … → 八番(L8)** 다음 진행에서 八番 승강장에 정차합니다.

HUD 는 이 규칙에 맞춰 **현재 이변 이름 + 대처법**을 보여줍니다.

---

## 2. 모드 주요 기능

### [기능 1] 단 1회 입력으로 즉시 8번 승강장 도착 (Instant Platform 8)
* **단축키**: **`F8`** 또는 키보드 숫자 **`8`**
* 역 진행 수(`PlayerState.CountNumber`)를 八番 직전으로 맞춘 뒤, 지금 타고 있는 칸의 `BP_Train.MoveNextStation()` 을 호출합니다.
  진행 수가 최대값(9)에 닿으면 게임이 직접 `Goal()` 을 실행해 **八番 승강장에 정차**합니다. 문이 열리면 내리면 됩니다.
* 발동 시 현재 칸의 이변을 해제하고, 도착할 때까지 새 이변도 계속 해제합니다 (`DisableAnomaliesAtPlatform8`).
* 치트로 도착해도 내려서 클리어하면 게임의 정상 엔딩/도전과제 처리가 그대로 진행됩니다.

### [기능 2] 키 입력 없는 자동 세이브/해금 완전 초기화 (Auto Full Reset)
* 게임 실행 시 자동으로 세이브를 순정 새 게임 상태로 되돌립니다 (`AutoReset = true`):
  * `Clear = false`, `AllAno = false`, `AnomalyEncount = false`
  * `All Anomaly`(31종) → `Not Found Anomaly` 로 100% 복원
  * `Hard Anomaly` 12종 복원 (`GameInstance:Reset AnomalyArray()`), 걸음 수 0
  * `SaveGameParam()` 으로 `Save.sav` 에 저장
* **주의**: 켜 두면 게임을 켤 때마다 발견한 이변 기록이 지워집니다. 기록을 유지하려면 `config.lua` 에서 `AutoReset = false`.

### [기능 3] 수동 세이브 완전 초기화 단축키
* **단축키**: **`F7`** — 플레이 도중 언제든 세이브를 새 게임 상태로 리셋합니다 (현재 역 진행은 그대로).

### [기능 4] 화면 좌측 상단 이상현상 실시간 HUD
* **단축키**: **`F9`** (HUD On/Off 토글)
* UMG 오버레이 위젯. 게임 폰트(NotoSansJP)에는 한글이 없어서 엔진 기본 폰트(Roboto + DroidSansFallback)로 그립니다. 한글과 역 이름 한자가 모두 나옵니다.
* 표시 예:
  * 🔵 정상 칸: `[다음 역 一ヶ崎(L1)] 이상현상 없음 (정상 칸) >> 안전합니다. 다음 칸으로 계속 진행하세요!`
  * 🟠 찾기/행동 이변: `[다음 역 零山(L0)] [★ 신규 이변 스폰! ★] [숨은 이변] 'ZONE' 큰 눈 광고 >> 대처법: 큰 눈 광고를 찾아 원래대로 돌아올 때까지 바라보세요`
  * 🔴 위험 이변: `... 안쪽 문 앞의 마네킹 (조명 깜빡임) >> 대처법: 밝을 때 달려서 통과하세요 (틀리면 게임오버)`
  * 🟡 무해한 이변: `... 모든 출입문이 열림 >> 대처법: 무시하고 다음 칸 문으로 걸어가세요`
  * 🟢 八番 직전 / 도착: `[八番(L8) 도착] ★ 8번 승강장 도착 ★ >> 탈출 성공! 문이 열리면 열차에서 내리세요!`
* 이변은 칸을 옮기는 순간 추첨되므로(`CurrentAnomalyComp`), 게임이 이변을 켜는 약 2초 전부터 미리 표시됩니다.

### [기능 5] 플레이어 이동 속도 배율
* `MoveSpeedMultiplier` (기본 설정 2.0). 걷기/달리기/웅크리기에 모두 적용, 좌석에 앉아 있을 때는 건드리지 않습니다.

### [기능 6] 공포 수위 필터 / 특정 이상현상 안 나오게 하기
* **`MaxScareLevel`** (기본 2): 이 수위보다 무서운 이상현상은 나오지 않습니다.
  * 3: 전부 나옴 (원래 게임)
  * 2: 쫓아오기·갑툭튀·게임오버 이변 13종 제외 → 18종만 나옴 (마네킹 2종, 무궁화 소녀, 유령, 투명 존재, 머리/얼굴 없는 아저씨, 뒤돌아보지 마라, '열어 주세요', 거인의 손, 군중, 침수, 정전)
  * 1: 괴이한 모습 이변 10종까지 제외 → 순한 8종만 나옴 (광고 2종, 비밀번호 퍼즐, 기울기, 사진 아저씨, 문/손잡이 움직임, 출입문 열림)
* **`ExcludedAnomalies`**: 수위와 상관없이 추가로 뺄 태그. 31종 태그와 한글 이름, 공포 수위는 `config.lua` 주석에 있습니다.
* 게임은 **아직 못 본 이변(세이브 `Not Found Anomaly`)에서 먼저 뽑고**, 다 보면 `GameInstance.UseTag` / `AnomalyManager.UseTag_ChangeMana` 에서 뽑습니다. 모드는 이 목록들과 `Hard Anomaly` 에서 제외 태그를 1초마다 빼 둡니다.
* 그래서 제외한 이변은 게임 안에서 **"이미 발견한 이변"** 으로 취급됩니다 (엔딩의 발견 개수에 포함).
* 검증: 31종 중 6종만 남기고 게임의 `SpawnAnomalyActor` 로 18번 뽑았을 때 18번 모두 남긴 6종만 나옴. 후보 목록만 뺐을 때는 제외한 이변이 18번 중 17번 나왔음 (미발견 목록이 우선이라서).
